# SWA Inventory

**SWA Inventory** is a Flutter-based asset management application designed to simplify company inventory management and asset tracking.

## Overview

SWA Inventory aims to help organizations manage asset records, monitor asset conditions, track asset locations, and organize inventory-related activities through a modern and user-friendly interface.

## Features

- **Dashboard** — View an overview of inventory and asset conditions.
- **Asset Management** — Create, view, update, and manage asset records.
- **Asset Borrowing** — Track asset borrowing and return activities.
- **Maintenance Management** — Record asset maintenance activities.
- **Location Tracking** — Organize assets by location and assigned personnel.
- **Asset History** — Review asset activity and changes.

## Tech Stack

- Flutter
- Dart

## Getting Started

### Prerequisites

Make sure you have installed:

- Flutter SDK
- Dart SDK
- Visual Studio Code or Android Studio
- An Android emulator or physical Android device

### Installation

1. Clone this repository:

   ```bash
   git clone <YOUR_REPOSITORY_URL>
   ```

2. Navigate to the project directory:

   ```bash
   cd swa-inventory
   ```

3. Install the dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
